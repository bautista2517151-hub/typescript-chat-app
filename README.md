📌 Project Description
ChatApp is a real-time messaging application that allows users to communicate with one another through instant messages. It uses Node.js, Express, and Socket.IO to enable communication between connected users.
The application provides an online users section, a chat area, and a message input box where users can send and receive messages.
✨ Features
Online Users – Displays connected users.
Real-Time Messaging – Allows users to exchange messages instantly.
Chat Interface – Provides an area to view conversations.
Send Messages – Allows users to send messages through a text box.
Socket.IO Connection – Maintains real-time communication between clients and the server.
